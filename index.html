ما هو CSS؟

CSS هو اختصار لـ Cascading Style Sheets

يعني: أوراق الأنماط المتعاقبة

🤔 ما وظيفة CSS؟

CSS هي اللغة المسؤولة عن شكل ومظهر صفحات الويب:

  • 🎨 الألوان (Colors)
  • 📏 الأحجام والمسافات (Sizes & Spacing)
  • 🔤 الخطوط والنصوص (Fonts & Text)
  • 📐 التخطيط والتنظيم (Layout)
  • ✨ التأثيرات والحركة (Effects & Animation)
💡 القاعدة الذهبية:
HTML = المحتوى (ماذا نعرض؟)
CSS = التصميم (كيف نعرضه؟)

طرق كتابة CSS — 3 طرق أساسية

1️⃣ Inline CSS — داخل الوسم مباشرة

نكتب CSS داخل attribute اسمه style في نفس الوسم.

inline-css.html
<h1 style="color: blue; font-size: 30px;">
    مرحباً بالعالم
</h1>

<p style="color: green;">
    هذه فقرة خضراء
</p>

مرحباً بالعالم

هذه فقرة خضراء

⚠️ متى نستخدمها؟ نادراً! فقط للاختبار السريع.
السبب: صعبة التعديل — تخيل 100 عنصر تريد تغيير لونهم!

2️⃣ Internal CSS — داخل <style> في الـ head

نكتب كل CSS داخل وسم <style> في الـ <head>

internal-css.html
<!DOCTYPE html>
<html lang="ar">
<head>
    <meta charset="UTF-8">
    <title>صفحتي</title>
    <style>
        h1 {
            color: red;
            font-size: 40px;
        }
        p {
            color: gray;
        }
    </style>
</head>
<body>
    <h1>عنوان أحمر</h1>
    <p>فقرة رمادية</p>
</body>
</html>

عنوان أحمر

فقرة رمادية

✅ ميزة: كل التنسيقات في مكان واحد — سهل التعديل!
متى نستخدمها؟ صفحة واحدة صغيرة.

3️⃣ External CSS — ملف منفصل (الطريقة المحترفة! ⭐)

نكتب CSS في ملف منفصل بامتداد .css ونربطه بالصفحة.

index.html
<!DOCTYPE html>
<html lang="ar">
<head>
    <meta charset="UTF-8">
    <title>صفحتي</title>
    <!-- ربط ملف CSS الخارجي -->
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <h1>عنوان منسق</h1>
    <p>فقرة منسقة</p>
</body>
</html>
style.css
/* ملف CSS منفصل */
h1 {
    color: purple;
    font-size: 35px;
}

p {
    color: navy;
    font-size: 18px;
}

Selectors — كيف نختار العنصر الذي نريد تنسيقه؟

Selector = المحدد الذي يخبر CSS أي عنصر نريد تنسيقه.

لدينا 3 أنواع أساسية:

1️⃣ Element Selector — بالاسم مباشرة

نختار كل عناصر من نفس النوع.

element-selector.css
/* كل عناصر h1 في الصفحة */
h1 {
    color: blue;
}

/* كل عناصر p في الصفحة */
p {
    color: green;
}

2️⃣ Class Selector — بالـ class (الأكثر استخداماً! ⭐)

نختار عناصر محددة بنفس الـ class.

كيف نستخدمها؟

  • في HTML: نضيف class="..."
  • في CSS: نكتب .اسم-الكلاس (بنقطة قبلها)
class-example.html
<!-- HTML -->
<p class="special">فقرة مميزة</p>
<p>فقرة عادية</p>
<p class="special">فقرة مميزة أخرى</p>
style.css
/* فقط العناصر التي لها class="special" */
.special {
    color: red;
    font-weight: bold;
}

فقرة مميزة

فقرة عادية

فقرة مميزة أخرى

3️⃣ ID Selector — بالـ id (للعناصر الفريدة)

نختار عنصر واحد فقط بـ id فريد.

كيف نستخدمها؟

  • في HTML: نضيف id="..."
  • في CSS: نكتب #اسم-الـid (بـ # قبلها)
id-example.html
<!-- HTML -->
<h1 id="main-title">العنوان الرئيسي</h1>
<h1>عنوان عادي</h1>
style.css
/* فقط العنصر الذي له id="main-title" */
#main-title {
    color: orange;
    font-size: 50px;
}

العنوان الرئيسي

عنوان عادي

⚠️ قاعدة مهمة: الـ id يجب أن يكون فريداً في الصفحة — لا تكرره!
لكن الـ class يمكن استخدامه لعدة عناصر.
Selectorالرمزالاستخداممثال
Element بدون رمز كل العناصر من نوع معين h1 { }
Class . (نقطة) عناصر متعددة .box { }
ID # (شباك) عنصر واحد فريد #header { }

الألوان (Colors) — أهم جزء اليوم! 🎨

في CSS، يمكن كتابة الألوان بـ 4 طرق:

1️⃣ Color Names — بالاسم

color-names.css
h1 {
    color: red;
}

p {
    color: blue;
}

.box {
    background-color: yellow;
}

💡 متى نستخدمها؟ للاختبار السريع. يوجد 140 لون بأسماء إنجليزية.

2️⃣ Hexadecimal — الطريقة الأشهر! #

نكتب اللون بـ 6 أرقام/حروف بعد #

الصيغة: #RRGGBB (Red, Green, Blue)

hex-colors.css
h1 {
    color: #ff0000; /* أحمر */
}

p {
    color: #0000ff; /* أزرق */
}

.special {
    color: #9b59b6; /* بنفسجي */
}

3️⃣ RGB — Red Green Blue

rgb-colors.css
h1 {
    color: rgb(255, 0, 0); /* أحمر */
}

p {
    color: rgb(0, 128, 255); /* أزرق سماوي */
}

4️⃣ RGBA — مع الشفافية (Transparency)

rgba-colors.css
.box {
    background-color: rgba(255, 0, 0, 0.5); /* أحمر شفاف 50% */
}
💡 نصيحة: استخدم مواقع مثل coolors.co أو color.adobe.com لاختيار ألوان متناسقة!

تنسيق النصوص والخطوط

📏 حجم الخط (Font Size)

font-size.css
h1 {
    font-size: 40px;
}

p {
    font-size: 18px;
}

💪 سُمك الخط (Font Weight)

font-weight.css
.bold {
    font-weight: bold; /* أو 700 */
}

.normal {
    font-weight: normal; /* أو 400 */
}

↔️ محاذاة النص (Text Align)

text-align.css
.center {
    text-align: center;
}

.right {
    text-align: right;
}

.left {
    text-align: left;
}

🔤 نوع الخط (Font Family)

font-family.css
body {
    font-family: Arial, sans-serif;
}

h1 {
    font-family: 'Cairo', sans-serif;
}
الخاصيةالقيم الشائعةمثال
font-size px, em, rem, % 20px
font-weight normal, bold, 100-900 bold
text-align right, center, left center
color أي لون #333

المشروع العملي: بطاقة تعريف ملونة 🎨

الآن سنجمع كل ما تعلمناه في مشروع واحد جميل! 🎉

profile-card.html
<!DOCTYPE html>
<html lang="ar">
<head>
    <meta charset="UTF-8">
    <title>بطاقتي الشخصية</title>
    <style>
        body {
            background-color: #f0f0f0;
            font-family: Arial, sans-serif;
        }

        .card {
            background-color: #ffffff;
            width: 400px;
            padding: 30px;
            text-align: center;
        }

        .card-header {
            background-color: #667eea;
            color: white;
            padding: 20px;
        }

        .name {
            font-size: 32px;
            font-weight: bold;
            color: #2c3e50;
        }

        .title {
            font-size: 18px;
            color: #7f8c8d;
        }

        .bio {
            color: #34495e;
            font-size: 16px;
        }
    </style>
</head>
<body>
    <div class="card">
        <div class="card-header">
            <h1>بطاقة التعريف</h1>
        </div>
        <p class="name">أحمد محمد</p>
        <p class="title">طالب في Sunshine T Academy</p>
        <p class="bio">أحب البرمجة وأتعلم تطوير الويب!</p>
    </div>
</body>
</html>

📝 الواجب — 5 مسائل CSS

المسألة 1: بطاقة تعريف بأسلوبك

المطلوب: أنشئ بطاقة تعريف شخصية بمعلوماتك:

  • استخدم External CSS (ملف منفصل)
  • اختر ألواناً مختلفة عن المشروع
  • اجعل الاسم بحجم 36px وعريض
  • اجعل الوصف بلون مختلف

المسألة 2: تنسيق قائمة

المطلوب: أنشئ قائمة بهواياتك ونسقها:

  • عنوان بلون #3498db
  • كل عنصر في القائمة بلون مختلف
  • استخدم class للعناصر المهمة
  • اجعل النص محاذى للوسط

المسألة 3: صفحة ملونة

المطلوب: أنشئ صفحة "ألواني المفضلة":

  • 5 فقرات، كل واحدة بلون مختلف
  • استخدم Hex colors (#)
  • اجعل كل فقرة تشرح اللون بنفس اللون

المسألة 4: تنسيق صفحة HTML سابقة

المطلوب: خذ أي صفحة HTML عملتها سابقاً ونسقها بـ CSS:

  • أضف ألوان
  • غيّر أحجام الخطوط
  • استخدم classes و ids
  • اجعلها جميلة!

المسألة 5: 🏆 مشروع كامل — موقع شخصي ملون

المطلوب: حوّل موقعك الشخصي من المحاضرة 4 إلى موقع ملون:

  • أنشئ ملف style.css منفصل
  • اربطه بكل صفحات الموقع
  • اختر 3 ألوان رئيسية متناسقة
  • نسّق كل العناوين بنفس الأسلوب
  • اجعل الروابط بلون مميز
  • استخدم classes للعناصر المتكررة
  • اجعل كل صفحة لها header ملون
